npm run dev -> lanza la app
ng serve -> lanza el servidor
npm run build -> hacer un build, construye el proyecto
ng new proyecto --routing --style=css -> hace un build

CONEXION MONGO
    npm install express mongoose cors dotenv -> para instalar mongoose
    server.js -> lanza el servidor
    node server.js -> se deberia ver contectado a mongo y servidor corriendo

CREACION COMPONENETES
    crear el servicio app/core/services... y el modelo app/core/model...
    asegurarse de que HttpClientModule esté importado en tu app.module.ts o core-module.ts
    crear el componente html, ts y scss
    agregar la ruta en app.routes.ts
    iniciar backend (node server.js) y angular (ng serve)
